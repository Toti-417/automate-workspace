# Contributing to AutoMate Workspace

Thank you for your interest in improving AutoMate Workspace!

## How to Contribute
1. Fork the repository on GitHub.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/nama-fitur
   ```
3. Commit your changes with clear messages:
   ```bash
   git commit -m "feat: add new excel export option"
   ```
4. Push your branch to GitHub:
   ```bash
   git push origin feature/nama-fitur
   ```
5. Open a Pull Request on GitHub.

## Code Standards
- Keep components modular inside `src/tools/`.
- Ensure new features work client-side without requiring mandatory paid API keys.
- Run `npm run build` before submitting to confirm zero build errors.
